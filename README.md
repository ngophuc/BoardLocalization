Description
===========

This repository contains the python source code of method described in the paper [An image processing method to recognize position of sawn boards within the log by X. Li, G. Pot, P. Ngo, J. Viguier, H. Penvern in Journal of Wood Science and Technology, 2023]. You can obtain a preprint
from [HAL]([https://hal.science/hal-04945727v1](https://hal.science/hal-04173459/)) for free.
