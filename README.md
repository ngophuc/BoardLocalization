## Description

This repository contains the python source code of method described in the paper: **An image processing method to recognize position of sawn boards within the log by X. Li, G. Pot, P. Ngo, J. Viguier, H. Penvern in Journal of Wood Science and Technology, 2023**. You can obtain a preprint
from [HAL](https://hal.science/hal-04173459/) for free. 

## Installation

Python 3.14. From this folder:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Run the method:

`python main_SIFT_TM.py`

## Data 

Data can be download from: https://entrepot.recherche.data.gouv.fr/dataset.xhtml?persistentId=doi:10.57745/XCVQSG

Input folder name: face2

Output folders name: SIFT and Results
